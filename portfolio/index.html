Student Health Risk Prediction

Machine Learning-Based Health Classification System

Project Overview

Developed a machine learning-based student health risk prediction system that analyzes health and lifestyle-related attributes to classify students into different health-condition categories. The system uses CatBoost for multiclass classification and Balanced Accuracy for performance evaluation.

Problem Statement

Predicting student health conditions from multiple lifestyle and health-related factors can be challenging because the dataset contains both numerical and categorical features along with missing values. The project aims to build a reliable machine learning model capable of classifying students into appropriate health-risk categories.

Objectives

  • Develop a machine learning model for student health classification.
  • Analyze health and lifestyle-related student attributes.
  • Handle missing numerical and categorical data effectively.
  • Compare Random Forest with CatBoost classification.
  • Evaluate the model using Balanced Accuracy.
  • Generate health-condition predictions for unseen student data.

Key Features

  • Multiclass Classification: Classifies students as at-risk, unhealthy, or fit.
  • Data Preprocessing: Handles missing numerical and categorical values before model training.
  • Numerical Feature Analysis: Uses features such as BMI, heart rate, sleep duration, calorie expenditure, step count, exercise duration, and water intake.
  • Categorical Feature Handling: Processes features such as diet type, stress level, sleep quality, physical activity level, smoking/alcohol habits, and gender.
  • Random Forest Baseline: Uses Random Forest as a baseline ensemble classification model.
  • CatBoost Classification: Uses CatBoost gradient boosting to handle tabular data and categorical features effectively.
  • Balanced Accuracy: Evaluates model performance by giving equal importance to each health-condition class.

Technology Stack

Python Pandas NumPy Scikit-learn CatBoost Machine Learning Kaggle

System Capabilities

  • Student health-condition prediction
  • Multiclass classification
  • Numerical and categorical feature processing
  • Missing-value handling
  • Random Forest baseline modeling
  • CatBoost-based classification
  • Balanced Accuracy evaluation
  • Prediction on unseen test data

Challenges & Solutions

  • Missing Numerical Values: Used median imputation to fill missing numerical values while reducing the influence of potential outliers.
  • Missing Categorical Values: Replaced missing categorical values with an Unknown category.
  • Categorical Feature Compatibility: Converted categorical values into the appropriate string format so that CatBoost could process them correctly.
  • Model Selection: Compared a Random Forest baseline with CatBoost and selected CatBoost based on its better validation performance.
  • Class Evaluation: Used Balanced Accuracy instead of relying only on ordinary accuracy so that each health-condition class received equal importance.

Results

The CatBoost model achieved a Balanced Accuracy of approximately 87.8% on the validation dataset, outperforming the Random Forest baseline.
